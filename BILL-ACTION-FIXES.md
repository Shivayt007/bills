# Bill UI and action fixes — v1.7.2

- Kept large currency values inside dashboard and bill summary cards on narrow screens.
- Removed Android tap, long-press selection and copy highlights from payment choices and bill cards while preserving text selection in form fields.
- Added the previous unpaid rent, new cycle rent and combined total payable to the next-cycle invoice, PDF and image share view.
- Restored visible Close Bill and Delete Bill controls on the current mobile bill-detail screen.
- Added admin-password verification and an explicit confirmation checkbox before a bill can be closed or deleted.

No rental calculations, rates, database schema, customer records or routes were changed.
